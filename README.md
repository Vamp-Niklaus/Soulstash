# Soulstash 🍿

Soulstash is a modern, high-performance media discovery platform for Movies, TV Shows, and Personal Collections.

## Features
- **Cinematic UI**: Vibrant poster-textured dark backgrounds with sleek glassmorphic UI elements.
- **Smart Collections**: Create custom collections (Watched, Watchlist, Favorites) with live synchronization.
- **TMDB Integration**: Detailed media information, cast info, TMDB collection recommendations, and similar titles.
- **Microservice Architecture**: Scalable backend services for auth, user collections, content caching, and scraping.

## Getting Started

### Frontend (SPA)
```bash
cd spa
npm install
npm run dev
```

### Build
```bash
npm run build
```
